## 2. Security and Credential Hygiene

### CRITICAL: `backend/.env` Is Tracked in Git

**File:** `backend/.env` (tracked since first commit `ce2154e`)

Contains real/development secrets committed to version control:
```
JWT_SECRET=super_secret_foundit_jwt_key_change_in_prod_2026
CLOUDINARY_API_KEY=1234567890
CLOUDINARY_API_SECRET=abcdefghijklmnopqrstuvwxyz
```

**Impact:** Anyone with repo access can see these credentials in git history.

**Recommended fix:**
1. Add `backend/.env` to a root `.gitignore`
2. `git rm --cached backend/.env` (removes from tracking, keeps local file)
3. If any of these are real production credentials, **rotate them immediately**
4. Consider using `git filter-branch` or BFG Repo Cleaner to scrub history
